# The recommended engine. After installing, fetch the browser itself:
#
#   pip install -r requirements.txt -r requirements-playwright.txt
#   playwright install chromium
#
# Playwright's own bundled Chromium is enough on Medium, and that is a
# measurement rather than an assumption: headful, it was served exactly as
# well as system Chrome on the same URL. What Medium's Cloudflare refuses is
# the `HeadlessChrome` token in the User-Agent, which this engine never sends
# (see the README). `--browser-channel chrome` is available if you would
# rather drive an installed Chrome, but nothing requires it.
